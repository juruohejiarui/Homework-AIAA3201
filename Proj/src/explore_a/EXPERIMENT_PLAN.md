# 方向 A：Confidence 融合训练与组合实验计划

更新：2026-10-24。本文件记录用户已确认计划及待定实施细节；当前没有启动下载、预计算或训练。

## 1. 已确认的范围

- previous depth map 暂按紧邻前一帧处理，等待老师说明。当前实验定义使用前一帧原始预测，不递归使用融合结果。

- 遮挡/历史可用性处理分两版：无额外模型的规则版、有额外模型的学习版。

## 2. Confidence 的准确含义

模型原始输出为逐像素的当前/历史融合分数 logits，经 softmax 得到相对权重 `c_cur, c_hist`。可称为相对 confidence，但这不自动表示“深度正确概率”，也不表示绝对可靠度已校准。

设 `M_bounds` 为采样坐标及深度有效性硬掩码；遮挡模块输出历史可用性 `v`，规则版为 0/1，模型版可为 [0,1]。

`a = M_bounds * v`

`w_hist = a * c_hist / (c_cur + a * c_hist)`

`D_fused = (1-w_hist) * D_cur + w_hist * D_warp`

实际计算需用数值稳定的归一化；无历史、首帧或跨场景时显式回退当前预测。softmax 的两个权重和为1，因此二者都不可靠的情况不能仅靠这两个数表达。若后续声明绝对 confidence，应另定义误差事件/方差、监督和校准评价。

需要区分三种量：光流对应可信度、历史可见/可用性、深度融合相对权重。对应位置可见不等于历史深度准确；深度变化也不必然代表遮挡。

## 3. 输入与模型输出

沿用 README 的 12 通道：当前 RGB(3)、warp 历史 RGB(3)、当前/warp 历史深度编码(2)、深度差(1)、历史可用性(1)、前后向流残差(1)、RGB 对齐残差(1)。其中硬有效性与可见性在内部单独保存，输入通道可使用两者乘积。

所有配置共用输入语义、深度单位、训练划分、尺寸和评价协议。GT 不进入推理输入；无效 GT 不参与监督。米制与相对逆深度不能混用，基础模型及表示须在实现前固定。

| ID | 结构 | 网络输出 |
|---|---|---|
| C | 浅层 CNN | 当前/历史两个相对 confidence logits |
| U | 轻量 U-Net | 当前/历史两个相对 confidence logits |
| R | 门控 + 深度残差头 | 两个 logits，以及有明确尺度限制的深度修正量 |

R 先算融合深度，再加残差修正；训练时应定义残差范围与深度正值约束。三者均保留 confidence 输出，R 额外输出残差。模型宽度、残差参数化和限制量为待定超参数。

## 4. 两种遮挡处理

### O0：规则版，不增加模型

使用前后向流一致性阈值与通用硬有效性约束。阈值只在开发集选择。这里“不使用模型”指不使用额外遮挡网络；RAFT 组合本身仍含预训练光流网络。

### O1：模型版，增加独立的可学习历史可用性模块

模块可读取两帧 RGB/warp 结果、双向流及其残差等，输出历史可用性。所有 O1 配置保持同一模块设计与监督定义；规则阈值剔除不再作为强制共同硬门，坐标越界和无效值约束始终保留。

此模块尚未确定使用现成权重还是自行训练，不能声称已经存在可直接接入的 checkpoint。KITTI/NYUv2 原始 RGB-D 不自动提供稠密真实遮挡标签：若自行训练，必须明确使用重投影可见性标签、规则伪标签、自监督信号或任务损失的哪一种。规则伪标签只是近似；只靠融合损失学习的输出更适合称“历史可用性”，不能直接宣称为真实遮挡概率。

已有相关预训练方法候选为 [MaskFlownet](https://github.com/microsoft/MaskFlownet)，作者提供预训练模型，内部学习粗遮挡 mask。但它是带学习遮挡机制的整套光流网络，不是任意 RAFT/Farneback 后面可直接插入的独立遮挡器。官方实现依赖旧 MXNet，内部 mask 的分辨率和语义也需适配。若直接替换光流网络，将改变光流因子，应另列附加实验，不能冒充本矩阵仅切换遮挡模块的受控对照。

## 6. 两套训练数据及抽样

### KITTI Raw + annotated train

- 监督锚点是 annotated train 中有 GT 的当前帧；从同一 drive、camera 的 Raw 获取真实前一帧。
- 只接纳两个 RGB 和当前 GT 实际存在的样本；不能将相邻“有标注帧”直接当原始相邻帧。
- 仅在有效深度像素监督；保留已有评价 drives，不将 val/test 混进训练。

### NYUv2 Raw

- 同一场景中配真实相邻 RGB，并同步当前传感器深度、转换和投影到 RGB 坐标。
- 保留时间戳/帧 ID；过大时间间隔、不同序列不能配成“前一帧”。
- 训练场景排除课程654测试图对应场景；开发集从其余训练场景划分。

### 抽样方法（预算待定）

1. 先按 drive/场景划分训练、开发和测试，再在各划分内抽样。
2. 优先覆盖更多不同场景，再限制每场景最多样本数，避免少数长视频占满预算。
3. 可以间隔选“当前帧锚点”，但每个锚点仍配其真实前一帧。每隔10帧取一个锚点不代表用 t-10 配 t。
4. 保留部分完整短片段用于连续视频评价；必要时另供时序损失训练。
5. 两数据源独立采样，显式设 batch/采样比例与损失权重，避免更大的来源淹没另一来源。比例尚未确定。
6. 记录固定清单、场景分配、原始帧 ID、有效 GT 比例。12个配置复用相同清单与预计算缓存；不增加全量哈希或例行 smoke test。
7. 先确定样本预算，再对所选数据预处理、预测与缓存；不必先把全部 Raw 展开、计算完再抽样。实际能否按场景下载取决于原压缩分包。

各数据分别保留有效深度范围和单位，训练可采用相对/对数误差并显式平衡来源。最终课程指标仍按各自正式协议计算，不把混合训练 loss 当作最终 benchmark 指标。

## 7. 训练监督与评价

通过最终深度对 GT 的有效像素损失训练 confidence，不强制人工生成 confidence 标签。可另研究边界损失，以及有前后帧 GT 支持的真实时间变化损失。仅优化单帧损失不能自动证明更稳定。

纯 CNN/U-Net 门控不能纠正两份候选同向共同偏差；R 的残差贡献需单列。两帧二维 warp 不修正真实 Z 变化，运动场景需检查历史误用。

结果表至少分数据域报告深度精度、边界、时序、效率，并保存 confidence/历史权重、可用性 mask、残差（R）和失败可视化。模型遮挡模块的训练/推理开销单独计入总成本。
