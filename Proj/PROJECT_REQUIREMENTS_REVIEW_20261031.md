## 与当前实现直接相关的核对

### 1. NYU 原生米制评价可用；对齐结果不能作为课程主结果

当前 labeled MAT 可读，大小 2,972,037,809 字节，images 为 (1449,3,640,480)，
depths 为 (1449,640,480)。splits.mat 为 795／654，代表性导出 RGB／GT 与 MAT 完全一致。
`depth_project/data/nyuv2.py` 已减1索引，并按新版要求转置 images 和 depths。

`explore_a/evaluation/nyu_labeled.py` 的未对齐分支采用规定的裁剪、米制范围、预测截断、
逐图等权及 DA-V2 指标函数。654张原生 Depth Pro：

- AbsRel = 0.1004695084
- RMSE = 0.3922163964 m
- δ1 = 0.9151581454

DA-V2／VDA 的 GT 辅助 inverse-SSI 数字不符合新版课程正式米制比较要求，不能放入同一
未对齐米制排名。KITTI/Sintel/Bonn 的论文式 SSI 表也只能是额外研究，不是新版必需成绩。
无需删除原始预测和旧数值，但今后不能继续把旧对齐口径当作课程要求。

当前三源训练 manifest 的分组 dev 不等同于课程指定的 795 张 labeled 开发图像。
应分别说明训练协议与课程划分，避免把 654 测试图用于调参、选模型或拟合尺度。

### 2. 指定片段与现有演示有实际差异

已检查本地官方仓库文件：
`third_party/Video-Depth-Anything/assets/example_videos/davis_rollercoaster.mp4`。
ffprobe 实际解码得到 70 帧，24 fps，960×540，时长约2.917秒。
当前文件的 Git blob 与仓库检出版本一致，不是本地修改版。

现有 `outputs/prepared_videos/official_demo_frames.npz` 为35帧、12fps、640×360，
source_indices为0,2,...,68。旧 DA-V2/VDA demo profiles 均为35帧FP16。
因此：

- 旧演示确实进行了时间抽样，不能作为原帧率演示交付。
- 新版“前100帧”与本地官方片段仅70帧存在实际不足；需核对上游版本／课程意图。
- 不能复制、插帧或改帧率凑100，然后声称是100个原始帧。
- 本次审阅没有重新下载、重跑演示，也没有擅自把70帧标成符合100帧要求。

### 3. 颜色归一化需区分不同模型与同一模型的改进

`depth_project/visualization/video.py` 对每份 relative 预测独立计算整段P1/P99。
这适用于DA-V2与VDA这两个不同relative方法的整段对照，但目前接口没有显式让某个relative
方法的改进版继承原版上下限，属于后续展示接口的潜在缺口。
用于“原模型 vs 改进模型”时，必须保存并复用原方法的上下限，不能分别重新拟合。
同样的colormap不意味着不同relative模型具有共同的米制颜色标尺。
当前metric_m路径已经使用共享minimum/maximum，不应把它误判为已经违反这一规则。

### 4. Stereo 公式正确，GT掩码边界不完全一致

`stereo/geometry.py` 已实现baseline毫米转米以及 f*B/(d+doffs)。
`stereo/matching.py` 已对 OpenCV 视差除16，已有15场景 BM 和 SGBM 结果，
包含 epe_valid_prediction 和 prediction_coverage。

但当前GT掩码是 finite & disparity>=0，并附加 disparity+doffs>0；新版要求是
finite & disparity>0。代码定义应明确对齐新版，并在报告说明无效预测规则。
本次读取15个已保存GT数组，共4,747,135像素，有限零视差像素为0；因此>=0改为>0这一项
本身不会改变现有结果，不能把它夸大为已经造成数值错误。若需重新汇总，可复用已有
stereo.npz，无需重做匹配。
左右一致性现在是可选诊断，不应作为课程必需GT评价的替代。

### 5. 三模型与无历史回退不是必须推翻的冲突

方向 A 的 warp、FB拒绝和置信度融合描述未变；Depth Pro 没有被排除。
unet_guided、flow_refine、final_flow、三源训练和3:3:2采样是用户选择的扩展实验，
不是课程必需内容，也没有因此失效。无需重制预测缓存。

两帧限制是当前实验协议，新PDF没有写“模型最多只能使用两帧”。
未得到用户调整前仍保留现有两帧方案，但报告不能称其为课程明文硬限制。

在用户要求的“无有效历史严格返回当前预测”规则下，独立NYU labeled测试不能产生
时序融合收益；画布缩放差异也不能算作学习收益。第5.2节要求同NYU协议对照，
第5.3节又明确视频改进可以采用受控定性和时间测量。合理落实方式是明确选择视频改进路线，
如实报告静态NYU回退结果，并在指定片段上与未改进方法比较。
不能用公共视频集的SSI数字代替NYU的无对齐课程结果。
